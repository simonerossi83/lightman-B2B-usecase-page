# Lightman B2B usecase page

Sorgente della landing Lightman Digital Show rivolta alle agenzie eventi.

## Avvio

Aprire `dist/index.html` nel browser. Nessuna compilazione necessaria.
Per un server locale: `python3 -m http.server 8000 --directory dist`.

## Struttura

- `dist/index.html`: contenuti e struttura della pagina.
- `dist/style.css`: stile responsive.
- `dist/app.js`: finestra contatto e preparazione email.
- `dist/assets/`: immagini e logo.

## Stato

Quattro video progetto da inserire. Calendario da collegare; attualmente sono disponibili chiamata diretta e preparazione di una richiesta via email.
La pagina contiene il meta tag noindex,nofollow.
I font Google richiedono una connessione Internet; sono previsti font di sistema alternativi.

## Clonazione sul Mac

```bash
git clone https://github.com/simonerossi83/lightman-B2B-usecase-page.git '/Users/simonerossi/Documents/Coding/David usecase'
```

La directory di destinazione deve essere assente o vuota. Se contiene già altri file, usare una sottocartella senza sovrascriverli.

Repository privata. Per clonarla occorre autenticarsi su GitHub con un account autorizzato.
